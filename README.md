# Internettside

En moderne og responsiv internettside som skal fikse alt.

## Om prosjektet

Dette er et webprosjekt under utvikling. Målet er å lage en funksjonell og brukervennlig internettside med moderne designprinsipper.

## Struktur

```
internettside/
├── index.html      # Hovedside
├── style.css       # Styling og layout
├── script.js       # JavaScript funksjonalitet
├── TODO.md         # Detaljert liste over hva som skal jobbes med
└── README.md       # Dette dokumentet
```

## Komme i gang

1. Åpne `index.html` i en nettleser for å se nettsiden
2. For utvikling, bruk en lokal webserver (f.eks. Live Server i VS Code)

```bash
# Med Python
python -m http.server 8000

# Med Node.js og npx
npx serve
```

3. Besøk `http://localhost:8000` i nettleseren din

## Funksjoner

### Implementert
- ✅ Responsivt design (mobil, tablet, desktop)
- ✅ Sticky navigasjon med smooth scrolling
- ✅ Hamburger-meny for mobile enheter
- ✅ Hero-seksjon med call-to-action
- ✅ Kontaktskjema med validering
- ✅ Fade-in animasjoner for seksjoner
