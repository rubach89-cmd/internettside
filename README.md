# Interaktiv Planteguide

En interaktiv nettside for planting og hagearbeid gjennom året.

## Funksjoner

### 🗓️ Århjul
- Visuell oversikt over alle 12 måneder
- Klikk på en måned for å se hvilke aktiviteter som passer
- Informasjon om såing, planting, stell og høsting for hver måned

### 🌱 Planteoversikt
- 12 forskjellige planter å velge mellom:
  - Poteter 🥔
  - Tomater 🍅
  - Gulrøtter 🥕
  - Salat 🥬
  - Agurk 🥒
  - Erter 🫛
  - Løk 🧅
  - Squash 🥒
  - Brokkoli 🥦
  - Gressløk 🌿
  - Jordbær 🍓
  - Gresskar 🎃

- Hver plante viser:
  - Kategori (rotgrønnsaker, bladgrønnsaker, etc.)
  - Stellnivå (lett, middels, mye)
  
### 📋 Plantedetaljer
Klikk på en plante for å se:
- Beskrivelse av planten
- Når den skal plantes
- Såing og planteinstruksjoner
- Stell og vedlikehold
- Høstingstid og metode

### 🧮 Plantekalkulator
Beregn hvor mye du trenger å plante:
- Velg plante
- Oppgi ønsket avling i kg
- Få resultat med:
  - Antall planter du trenger
  - Areal i m²
  - Radavstand
  - Planteavstand

**Eksempel:** For å få 10 kg poteter trenger du:
- 17 potetplanter
- 4.2 m² areal
- 70 cm radavstand
- 35 cm planteavstand

## Teknologi
- Ren HTML, CSS og JavaScript
- Ingen avhengigheter eller rammeverk
- Responsiv design for mobil og desktop
- Norsk språk

## Bruk
Åpne `index.html` i en nettleser, eller kjør en lokal webserver:

```bash
python3 -m http.server 8080
```

Deretter åpne http://localhost:8080 i nettleseren.
